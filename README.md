# Notes App — Docker deployment

Тестовое задание DevOps: контейнеризация готового FastAPI-приложения для заметок и запуск с PostgreSQL. Код приложения не изменялся.

## Требования

- Docker Engine и Docker Compose plugin (`docker compose`)
- Свободный локальный порт `8000`

## Быстрый запуск

В корне проекта создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

В `.env` задайте собственный `POSTGRES_PASSWORD` и проверьте `POSTGRES_DB`, `POSTGRES_USER`.

```bash
docker compose up -d --build
docker compose ps
```

## Решение и обоснование

| Компонент         | Реализация                                                               | Зачем                                                                       |
| ----------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Dockerfile        | Multi-stage, `python:3.12-slim`, отдельный `/opt/venv`                   | Отделение установки зависимостей от runtime, кеширование сборки             |
| Пользователь      | `USER 10001:10001`                                                       | Работа FastAPI без root                                                     |
| Запуск            | `CMD ["python", "wait_for_db.py"]`                                       | Проверка PostgreSQL перед стартом Uvicorn                                   |
| Ожидание БД       | SQL `SELECT 1`, повторные попытки, `DB_WAIT_TIMEOUT` (по умолчанию 60 с) | Независимость от механизма ожидания Docker Compose; пригодно для Kubernetes |
| Передача сигналов | `os.execvp()` заменяет wrapper на Uvicorn (PID 1)                        | Непосредственное получение SIGTERM приложением                              |
| PostgreSQL        | Отдельный сервис, именованный volume                                     | Сохранение данных между пересозданиями контейнера                           |
| Healthcheck       | `pg_isready` для БД, `/readyz` для приложения                            | Проверка готовности PostgreSQL и доступности приложения вместе с БД         |
| Остановка         | `stop_grace_period: 80s`                                                 | Время для завершения активных запросов и закрытия пула подключений          |
| Секреты           | Значения передаются из локального `.env`; `.env` исключён из Git         | Не хранить пароль в Dockerfile и Compose                                    |
